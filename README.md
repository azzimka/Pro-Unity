# Pro-Unity

Веб-приложение на **Django** для IT-академии. Сайт показывает категории и курсы, принимает заявки на обучение и даёт сотрудникам список заявок с поиском.

Это учебный проект: я сделал его, чтобы потренировать Django (модели, формы, шаблоны, админка).

## Что умеет

| Страница | Адрес | Что делает | Доступ |
|---|---|---|---|
| Главная | `/` | Выводит категории и курсы из базы данных | все |
| Запись на курс | `/register` | Форма заявки: имя, фамилия, направление, телефон. Данные сохраняются в базу | все |
| Страница категории | `/category/<slug>/` | Показывает одну категорию по уникальному `slug` | все |
| Список заявок | `/view-data/` | Таблица заявок с поиском по имени и по направлению (`?ism=...&it=...`) | только сотрудники (`is_staff`) |
| Админка | `/admin/` | Управление категориями, курсами и заявками, загрузка картинок курсов | сотрудники |

Страница `/view-data/` закрыта декоратором `staff_member_required`: без входа через админку она недоступна, потому что там лежат имена и телефоны.

---

## Модели

- **Category**: название и уникальный `slug`.
- **Course**: курс с изображением, заголовком, названием профессии, категорией (`ForeignKey`) и `slug`. Картинки сохраняются в `media/courses/`.
- **Registration**: заявка (`ism`, `familiya`, `it`, `telefon`).

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/azzimka/Pro-Unity.git
cd Pro-Unity
```

### 2. Создать и включить виртуальное окружение

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install django pillow
```

### 4. Создать базу данных

```bash
python manage.py migrate
```

База `db.sqlite3` создаётся этой командой и в репозиторий не входит.

### 5. Создать администратора

```bash
python manage.py createsuperuser
```

### 6. Запустить сервер

```bash
python manage.py runserver
```

Сайт откроется по адресу <http://127.0.0.1:8000/>.

### 7. Добавить данные

После `migrate` база пустая. Войди в админку <http://127.0.0.1:8000/admin/> и создай хотя бы одну категорию и один курс (с картинкой). Тогда они появятся на главной странице.

Чтобы открыть список заявок <http://127.0.0.1:8000/view-data/>, сначала войди через админку под учётной записью администратора.
