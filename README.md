# 🎓 Pro-Unity — Платформа IT-Академии / Учебного центра

**Pro-Unity** — это веб-приложение на базе **Django (Python)** для образовательного IT-центра. Платформа позволяет презентовать направления обучения, собирать онлайн-заявки от потенциальных студентов, а также просматривать и фильтровать списки зарегистрированных учеников.

---

## 📌 О проекте

Проект решает ключевые задачи для учебного центра или IT-школы:
1. **Презентация курсов и направлений**: демонстрация образовательных программ (Frontend, Python / Backend, UI/UX Дизайн, Маркетинг и др.).
2. **Лидогенерация / Запись на курсы**: удобная форма сбора контактов и выбора специальности для новых студентов.
3. **Управление заявками (CRM-функционал)**: отдельная страница просмотра базы поступивших заявок с возможностью быстрого поиска и фильтрации.

---

## 🚀 Основной функционал

### 1. Главная страница (`/`)
- Баннер и визитка IT-центра («Научитесь работать в IT: практика на реальных проектах, помощь с трудоустройством»).
- Динамический вывод списка доступных категорий и курсов из базы данных.
- Быстрый переход к записи на обучение.

### 2. Запись на курсы / Регистрация (`/register`)
- Форма подачи заявки (`RegistrationForm`):
  - **Имя** (`ism`)
  - **Фамилия** (`familiya`)
  - **Направление обучения** (`it`)
  - **Номер телефона** (`telefon`)
- Автоматическое сохранение данных в базу данных.

### 3. Просмотр и фильтрация учеников (`/view-data/`)
- Таблица с полным списком зарегистрированных студентов и их контактами.
- Поисковая система с фильтрацией:
  - Поиск по **имени** студента.
  - Поиск по **направлению обучения** (например, Python, Дизайн и др.).

### 4. Страница направления (`/category/<slug>/`)
- Детальный просмотр конкретной категории курсов по уникальному URL (slug).

### 5. Панель администратора (`/admin/`)
- Управление категориями (`Category`), курсами (`Course`) и заявками (`Registration`).
- Загрузка изображений для направлений курсов.

## 🛠 Стек технологий

- **Backend:** Python 3, Django
- **Frontend:** HTML5, CSS3, Django Templates
- **База данных:** SQLite (`db.sqlite3`)
- **Медиа/Статика:** Django Static & Media files

## 💻 Установка и запуск проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com/azzimka/Pro-Unity.git
cd Pro-Unity
```

### 2. Создание и активация виртуального окружения
```bash
# macOS / Linux:
python3 -m venv venv
source venv/bin/activate

# Windows:
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install django pillow
```

### 4. Применение миграций
```bash
python manage.py migrate
```

### 5. Создание суперпользователя (для админки)
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```

После запуска сайт будет доступен по адресу:
- Главная страница: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- Запись на курсы: [http://127.0.0.1:8000/register](http://127.0.0.1:8000/register)
- Список заявок: [http://127.0.0.1:8000/view-data/](http://127.0.0.1:8000/view-data/)
- Панель администратора: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
